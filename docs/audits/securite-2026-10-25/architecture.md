# Architecture · OmegaX (d1e16b3)

1. **Product, principals, resources.** Multi-tenant accounting SaaS (SYCEBNL/SYSCOHADA, DR Congo) run by VMG Consulting; also an on-site Windows install (`MODE_INSTALLATION=SUR_SITE`). Each tenant is a "dossier" (`tenantId`). Principals: anonymous Internet; five tenant roles (ADMIN_CABINET, COMPTABLE, LECTURE_SEULE, AIDE_COMPTABLE inheriting comptable/lecture except `@ReserveAuComptable`, GESTIONNAIRE_PAIE closed by default and opened per route by `@AccesRolesCantonnes`); group head ("siège") reading/writing its cells via `perimetreDeGroupe`; VMG platform operator (`estOperateurPlateforme`, granted at boot from env `OPERATEURS_PLATEFORME`, console needs 2FA + full login < 8 h); on-site installation administrator. Protected resources: every tenant's ledger, payroll and personal data, bank details (RIB) and payment orders, audit chain, licences, the publisher tenant (`PROPRIETAIRE`), production DB and CI secrets.

2. **Comparable baseline.** Sage 100 i7 (UI/function reference, `docs/comparaison-sage/`), Odoo (`docs/architecture-odoo-inspiration.md`). No source-grounded security baseline.

3. **Stack and deployment.** NestJS 10 / Express 4 / Prisma 5 / PostgreSQL (Neon PG18 hosted, PG17 on-site); React 18 + Vite, HashRouter. Hosted: Cloud Run (`--allow-unauthenticated`, no `--ingress`), Firebase Hosting relays `/api/**`, server strips `/api` (`src/bootstrap.ts:14-34`), `trust proxy` = 2 hosted / 0 on-site (`src/common/sauts-de-confiance.ts`). On-site: WinSW `installation/demarrer.cjs`, HTTP on LAN, cookie Lax without Secure, server listens on all interfaces (`src/main.ts:28`). Offline limits: no OS sandbox assembled; this run is source-only, no target code executed; PG16 only locally; no Playwright/k6.

4. **Entry surfaces and paths.** Anonymous: `/auth/login|logout|register|inscription-essai(+/etat)` (`src/modules/auth/auth.controller.ts:57-170`), `/health`, `/sur-site/etat`, `/sur-site/licence` (Ed25519 signed file). Authenticated: 107 controllers under `src/modules/*`. Files in: base64 xlsx/csv import (`src/modules/import/lecture-fichier.ts:165,217`, also rapprochement, consolidation, groupe canevas; body cap 12 MB, no decompressed-size cap), multer uploads 5 MB typed by magic bytes (`src/common/pieces-jointes/`, `tiers/documents-tiers`, `virements-fonds`). Data out: tenant ZIP of CSV (`src/modules/exports/restitution/`, CSV writer `lecture-fichier.ts:131-139` without formula neutralisation), Excel exports, PDF/print. Text sinks: token templates (`relances/relances.service.ts:720-739`, `remises/remise-en-banque.ts:243-251` use string `.replace` with user values; `tiers/modeles-impression.ts` function replace), outbound mail via nodemailer (`courrier/transport-courriel.ts:198-217`) to tenant-chosen addresses. Raw SQL: tagged templates with manual `tenantId`; `purger-dossier.ts` uses `$executeRawUnsafe` with schema-derived identifiers. Logs: `BaseExceptionFilter` stacks to Cloud Run logs; SMTP error messages logged (`auth.service.ts:377`).

5. **Trust boundaries and strongest controls.**
   - Authentication: JWT HS256 (`JWT_SECRET`, weak secret only warns, `src/config/validate-env.ts:34-41`) in httpOnly cookie `__session` or Bearer; CSRF = header equals JWT claim on cookie writes, Bearer exempt (`src/modules/auth/jwt.strategy.ts:103-111`); per-request DB reload, revocation `sessionsInvalidesAvant`, closed sessions list; lockout after bcrypt; TOTP with replay step (read-then-write, non-transactional).
   - No global JwtAuthGuard: per-controller `@UseGuards`; `RolesGuard` lets routes without `@Roles` through (`src/common/guards/roles.guard.ts:26-27`), coverage held by `ecritures-reservees.spec.ts`; function profiles open by default when undeclared (`src/common/fonctions/fonctions-metier.ts:202-221`); `LicenceGuard` read-only when expired; `ReferentielGuard`.
   - Tenant isolation: Prisma extension (`src/common/cloisonnement/extension-cloisonnement.ts:238-367`) bounding collections by value, re-reading owners on writes, null on foreign unit reads. Gaps visible in source: tenant context set by an interceptor that runs after guards (guards and anonymous routes run without tenant context), models outside `MODELES_CLOISONNES` (e.g. `Tenant`) unguarded, nested writes not inspected, raw SQL and `clientNu` bypass the extension; 40 `horsCloisonnement` call sites (auth, plateforme, essais-echus, groupe).
   - Platform: operator guard (2FA + recent full login); operator email granted by exact match at boot (default `admin@vmgconsulting.net` in workflow); admin password reset drops 2FA and does not exclude operator accounts; address change does not verify the new address.
   - Audit chain: hash-chained, no DB-level protection.
   - CI: production secrets are repository secrets (no protected environments); `requetes-production.yml` read-only relies on `PGOPTIONS` plus a textual filter; actions pinned by tag.
   - On-site: anonymous `/sur-site/*`; first `register` open on a fresh install; backup external copy to arbitrary path (UNC) for the installation admin.
   - Client: CSP `script-src 'self'`, no DOM HTML sinks found, CSRF token in localStorage, service worker without fetch handler.

6. **Starting paths.** `src/modules/auth/`, `src/common/{guards,cloisonnement,audit,perimetre,fonctions}/`, `src/modules/{plateforme,groupe,licence,sur-site,utilisateurs}/`, `src/modules/exports/`, `src/modules/import/`, `src/common/pieces-jointes/`, `src/modules/{relances,remises,courrier,tiers,reglements}/`, `src/modules/comptabilite/`, `.github/workflows/`, `installation/`, `client/src/lib/`, `client/firebase.json`.

7. **Prior coverage.** No prior ledger or findings.json in this skill's format. Internal campaigns of 2026-10-22/23 exist but are not carried; no exclusions.

8. **Companion selection.** WEB-PROTOCOL-AND-AUTH (cookie session, CSRF, JWT, MFA, password reset, forwarded-header trust); DATA-ISOLATION-AND-LIFECYCLE (tenant extension, export/restitution, import); CLIENT-SIDE (SPA, localStorage, CSP); SUPPLY-CHAIN-AND-RELEASE (privileged workflows, secrets); CLOUD-AND-DEPLOYMENT (trusted-proxy, ingress, on-site network); RESOURCE-EXHAUSTION-AND-AVAILABILITY (xlsx decompression on a 460 MiB heap). Excluded: MEMORY-SAFETY-AND-BINARY (no native code), AI-AND-LLM (no model in product), PROTOCOLS-RPC-AND-MESSAGING (no RPC/broker; mail is outbound only), DESKTOP-MOBILE-AND-LOCAL-IPC (no native app; on-site is a LAN web server).
